# ZUNAREBORN Web 2.12 — Diseño, navegación y accesibilidad

Actualización acumulativa sobre 2.11. **No crea una nueva clave de almacenamiento**: mantiene `zunareborn.v2`. Se conserva el historial y las funciones existentes.

## Cambios
- Accesos directos a Misiones, Registrar entrenamiento, Nutrición y Objetivos en Inicio.
- Próxima misión pendiente con nombre, categoría y XP de la tarea.
- Accesos internos en Movimiento: Plan semanal, Sesiones, Biblioteca y Nutrición.
- Navegación con estado accesible (`aria-current`) y enlace para saltar al contenido.
- Mejoras para pantallas pequeñas, objetivos táctiles, foco de teclado y movimiento reducido.
- Identificación visual 2.12 y revisión del caché offline.

## Actualizar GitHub Pages
1. Desde la v2.11, exportar una copia de seguridad en Perfil.
2. Subir **los diez archivos** de esta carpeta a la raíz del repositorio, reemplazando los existentes.
3. Confirmar en `main`, y comprobar la actualización en Safari.
4. Revisar hábitos, XP, objetivos y entrenamientos existentes.

## Límites de esta actualización
Las mejoras son de interfaz y accesibilidad. No se agregó backend, notificaciones push ni podómetro automático. No se afirma que la aplicación haya sido probada en todos los dispositivos.
