# ZUNAREBORN Web 2.7 — Especialidad deportiva

Basada en la versión 2.6. Actualización incremental para GitHub Pages.

## Novedades
- Habilidades por disciplina: running, fútbol, gimnasio, ciclismo, básquet, natación u otro.
- Posición específica en fútbol (defensa, mediocampo, ataque, arco).
- Guías introductorias breves para practicar habilidades de forma segura.
- Autoevaluación de 1 a 5 y nota personal para seguir evolución por deporte.
- Conserva sesiones anteriores y configuración deportiva de 2.6.
- No da XP por autoevaluaciones para evitar recompensas duplicadas.

## Limitaciones
- Los consejos son generales; no analizan vídeo ni sustituyen entrenamiento individual con profesional.
- No hay contador automático de pasos ni integración con datos de salud.
- No hay notificaciones push con la app cerrada.
- Los datos siguen guardados localmente en el dispositivo; exportar copia desde Perfil antes de actualizar.

## Instalación
1. Exportar copia desde Perfil.
2. Descomprimir el ZIP.
3. Subir todos los archivos de esta carpeta **a la raíz** del repositorio GitHub existente, reemplazando los de igual nombre.
4. Esperar el despliegue GitHub Pages y verificar que XP, hábitos, objetivos y sesiones sigan intactos.
