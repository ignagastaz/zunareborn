# ZUNAREBORN 2.14 — Evolución física opcional

Actualización acumulativa sobre 2.13. Mantiene la clave local `zunareborn.v2`, XP, misiones, objetivos, entrenamientos, biblioteca y planificación de comidas.

- Historial voluntario de peso con fecha para adultos (18+).
- Gráfico de hasta 12 registros y lista de los últimos 8.
- Permite corregir una medición guardando la misma fecha y eliminar registros.
- Los datos se incluyen en la exportación JSON; no se envían a un servidor.
- No se calculan dietas, calorías, IMC ni objetivos de peso.

Antes de actualizar: exportar copia desde Perfil. Subir los 10 archivos a la raíz del repositorio GitHub Pages. Confirmar en `main`. Verificar en iPhone.
